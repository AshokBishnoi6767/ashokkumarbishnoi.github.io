# Ashok Kumar Bishnoi Portfolio

Static two-page portfolio website for GitHub Pages.

## Files
- `index.html` — introduction/about page
- `portfolio.html` — selected work, achievements and content metrics
- `styles.css` — responsive site styling
- `assets/profile.jpg` — profile image

## GitHub Pages
Upload all files to the root of the `ashokkumarbishnoi.github.io` repository, then enable Pages from the `main` branch root.
